# MyResearch 产品设计文档

版本：1.0 · 2026-09-19 · 状态：实施基线，构建与验收结果另见 README / GitHub Actions。

## 1. 定位与依据

一款原生 iOS 单手搜索启动器。主路径是「点主屏幕图标 → 键盘自动出现 → 输入 → 一次点击选择搜索词和目标」。它不是聚合搜索结果的浏览器，也不是以分享扩展或 AI 对话为中心的工具。

需求依据是用户在旧手机实际操作 OneSearch / Lookup 后的描述。用户口述优先于历史宣传截图；不照搬原应用商标、图标、二进制或私有资源。产品名暂用仓库名 MyResearch。

首要目标：原始搜索词的位置稳定；打开后无需再点击输入框；所有搜索源可以自行维护，不再依赖已下架产品。

## 3. 信息架构

三个页签保持为「搜索 / 我的链接 / 设置」。键盘展开时隐藏底部页签，给搜索区让出空间；顶部提供收起键盘按钮，收起后恢复页签。导航到编辑/设置页面时不自动弹键盘。

### 3.1 搜索页：跟手布局

```text
┌─────────────────────────────────┐
│ MyResearch               收键盘 │
│                                 │
│ 搜索到                          │
│ Google          g             ↗ │
│ 哔哩哔哩        b             ↗ │
│ 小红书          xhs           ↗ │
│ ……目标区可独立滚动              │
├─────────────────────────────────┤
│ 联想 · Bing                     │
│ 春莱布年龄         [G] [B] [红] │
│ 春莱布性别         [G] [B] [红] │
│ ……候选区可滚动                  │
├─────────────────────────────────┤
│ 原词 春莱布        [G] [B] [红] │ ← 独立固定区域
│ [ 搜索内容…    粘贴 清空 搜索 ] │ ← 键盘上方
├─────────────────────────────────┤
│            系统键盘             │
└─────────────────────────────────┘
```

这里的 G/B/红仅为线框示意，实际使用有名称的本地图标。首页不是永久显示一个巨大宣传标题或空白 Hero 区。

**布局硬规则**：原词行绝不能放进联想数组，也不能放进联想 ScrollView。它有稳定标识与独立布局容器。建议数量 0→1→8、超时、旧请求晚回、重复词过滤、加载提示变化，都不能改变原词行相对键盘的纵向位置。原词行与输入框只随键盘、安全区和用户选择的布局模式移动。

目标区和候选区分配各自的高度与滚动空间，候选更新不得把全部主要目标推出页面。小屏幕/横屏首先缩减滚动区域，不能裁切原词和输入框。键盘自动避让依靠系统安全区，不把固定的“键盘高度 300”写死。

### 3.2 输入与点击语义

1. 输入普通关键词：目标列表使用当前关键词；候选正文使用默认目标；右侧按钮使用该按钮的目标。
2. 输入 `b 春莱布` 或 `春莱布 b`：完整匹配别名后提示目标为哔哩哔哩；实际发送的关键词不包含 `b`。候选右侧按钮仍可显式覆盖目标。
3. 键盘「搜索」：有完整 Trigger 使用其目标；没有则使用设置中的默认目标。单独输入 `b` 不被当成空搜索执行。
4. 闪电模式表示少一次选择，不表示输入每个字母时自动离开 App。提交必须由键盘搜索、目标按钮或候选点击触发，防止输入法组词期间误跳转。
5. 中文/日文输入法 marked text 期间不发联想请求、不解析或执行 Trigger；提交词后才刷新。
6. 回到 App 保留查询，方便换一个来源继续搜。清空按钮一按恢复空状态；不自动读取剪贴板，仅显式点击粘贴时读取。
7. 未输入关键词时可展示最近历史与来源列表；搜索型目标不发空查询；固定动作链接可以直接打开。

### 3.3 候选与联想

原词永远保留且固定；远端返回完全相同的字符串要去重。候选按引擎返回顺序显示，不将原词重新插入第一条。单条候选正文可一键搜索；小箭头可把候选填入输入框继续编辑，不能混淆两种操作。

远端请求使用约 250ms 防抖、取消前一任务、响应世代校验、短超时与内存缓存。断网/限流/解析失败只降级为本地历史与状态提示；不制造假联想，不阻止原词搜索。切换引擎、关闭联想或清空输入后旧响应不得回填。

默认联想来源为 Bing；设置明确告知输入的关键词会发送给所选第三方。Google/Bing 的公开联想入口不是本项目可保证稳定的服务；无账号、无 API Key、无 SLA，可随时关闭。使用临时网络会话，不携带本项目账户信息；应用无自建服务器和遥测。

## 4. 我的链接

列表显示图标、名称、Trigger 概览、启用状态；支持编辑按钮/拖拽把手手动排序。排序控制首页与快捷按钮的相对次序；搜索次数不改变人工顺序。

新增入口允许「从预设添加」和「创建自定义链接」。预设以可编辑的普通记录存入本地；之后不被后台在线更新覆盖。重复加入同一预设应提示，不能悄悄产生多个重复项。

编辑页字段：名称；图标符号与颜色；URL 模板；可选网页兜底；Trigger 别名；启用；是否显示在候选右侧。右侧快捷来源最多显示前三个已启用且勾选的链接，顺序来自手动排序；其余来源仍可从首页使用。

模板示例：

```text
https://www.google.com/search?q={query}
exampleapp://search?keyword={query}&tab=all
https://example.com/find/{query}/details
```

所有 `{query}` 位置均替换为 UTF-8 百分号编码后的值。默认使用 RFC 3986 unreserved 字符集；`&`、`+`、`#`、`?`、`/`、中文、emoji 不得逃逸成额外 URL 参数。不把已生成 URL 再整体编码。不提供默认不安全的“原样插入”模式。

编辑器显示测试关键词、解析后的完整 URL 与「测试打开」。校验名称、URL scheme、空白、未知占位符、过长值、Trigger 重复与跨链接冲突。禁止 `javascript:`、`data:`、`file:` 及递归打开自身的链接。网页必须有有效主机；兜底仅允许 HTTPS。允许没有占位符的链接，编辑页提示它是固定动作、不携带搜索词。

可编辑 HTTPS 预设优先保证网页降级；Universal Link 是否交给目标 App 由系统及目标 App 决定，不把“网页 URL 有效”说成“原生搜索 Scheme 已经真机验证”。用户自定义 Scheme 调用失败后只尝试一次 HTTPS 兜底；仍失败显示可复制的错误，不循环跳转。

## 5. 设置与数据

搜索体验：自动键盘默认开、跟手布局默认开、闪电模式默认开、默认搜索来源、联想引擎、最大候选数、历史记录开关。手动排序直接在「我的链接」操作，不另做“智能排序”覆盖它。

数据：本地 JSON 原子写入；导出链接与设置，不含搜索历史；导入前展示数量并二次确认替换；严格检查版本、重复 ID、别名冲突及模板。写入失败要反馈；损坏文件保留，不静默覆盖原始配置。清空历史是独立确认操作。

跨设备迁移使用导入导出，不在第一版假设自签证书支持 iCloud 或 App Groups。应用内不保存 Apple ID、签名证书或 API 密钥。

## 6. 快速搜索扩展与签名边界

扩展是次要入口，不牺牲主页体验。第一版可以接收共享文字或网页 URL，选择来源后在扩展内展示网页搜索；提供复制最终链接。不能承诺 Share Extension 可通过公开 API 任意启动另一个 App，也不使用 responder-chain/私有 selector 伪造成功。

主 App 与扩展的存储是隔离的。默认未签名交付不要求 App Groups，以降低用户重签门槛：扩展可以使用内置预设或导入主 App 导出的 JSON；不谎称自动同步了主 App 自定义来源。后续持有支持 App Groups 的签名能力时再增加自动共享配置。

同时提供含扩展的完整 IPA 和去除扩展的 core IPA；后者适合不需要系统分享扩展的安装方式。LiveContainer 下不保证扩展被系统注册。两个包使用相同主 Bundle ID，是替代安装，不是两个可并存产品。

## 7. 技术实现与交付

原生 SwiftUI + 必要的 UIKit 输入组件；最低 iOS 17。纯 Foundation 搜索核心独立成 Swift Package，允许在 Linux/macOS 执行单元测试；无第三方运行时依赖。工程由仓库脚本确定性生成，不要求用户配置 npm、CocoaPods 或远程 Swift 包。

模块：Core（模型、模板、Trigger、导入校验、候选整理）；App（持久化、联想网络、输入框、搜索 UI、链接编辑、设置）；Share（文字输入、来源选择、网页结果）；Tests（核心逻辑）；UITests（自动键盘、原词固定、链接编辑等）。

GitHub Actions 在 macOS / Xcode 编译真实 iphoneos arm64 App，关闭代码签名，打包 `Payload/MyResearch.app` 为 `.ipa`，生成 SHA-256 与构建元数据。产物必须是设备构建，不能把模拟器 `.app` 改后缀冒充 IPA。签名证书不进入仓库或 Actions。

交付内容：本设计文档、源代码、测试、工作流、安装说明、未签名 IPA（完整/core）和可追溯的构建记录。未签名 IPA 不可直接点开安装，需要用户现有签名/安装工具；扩展还需工具能一起签名。具体成功与否以实际 Actions 日志和产物为准，代码提交不等于构建成功，构建成功不等于所有第三方 App 已真机兼容。

## 8. 验收用例

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 冷启动搜索页 | 默认自动出现键盘；输入框可直接输入 |
| A02 | 输入春莱布，候选异步出现/增减 | 原词行始终为候选下方独立固定行；坐标不随候选数变化 |
| A03 | 点击原词正文 / 右侧三个来源 | 关键词相同；目标分别按默认或按钮决定；只发一次打开请求 |
| A04 | 点候选正文 / 填入箭头 | 正文执行搜索；箭头仅回填，不跳转 |
| A05 | 前缀、后缀、大小写 Trigger | 完整边界识别；去除 Trigger 后发送；中文中间子串不误识别 |
| A06 | 输入法拼音/假名组合中 | 不误提交，不覆盖 marked text，不发送未提交片段 |
| A07 | 测试 A&B + C/#? 和 emoji | 参数完整编码，不能产生额外 query/fragment |
| A08 | 旧联想请求晚到、离线、关闭联想 | 不显示过期建议；原词始终能搜 |
| A09 | 编辑、禁用、删除、拖拽后重启 | 配置与顺序持久；禁用项不参与 Trigger 或快捷按钮 |
| A10 | 默认来源被禁用/删除 | 明确回落到第一个启用来源；全部禁用显示可操作空态 |
| A11 | 导入损坏/未来版本/冲突 JSON | 拒绝并解释；原配置完全不变 |
| A12 | 导出后重新导入 | 名称、模板、别名、顺序、设置保持；不意外泄漏历史 |
| A13 | 字体放大、深色、小屏、横屏 | 核心输入不遮挡；点击目标至少 44pt；长名称不挤掉快捷按钮 |
| A14 | 第三方 App 未安装/Scheme 不支持 | 尝试一次配置的 HTTPS 兜底；失败有明确反馈 |
| A15 | 分享扩展 | 支持文本；没有共享配置权限时说明预设/手动导入，不假同步 |
| A16 | IPA | 真机 arm64、Info.plist 正确、无证书或 provisioning profile、SHA-256 可复验 |

自动化覆盖可验证的逻辑与模拟器交互；第三方 App 跳转、中文键盘细节及真实拇指触达仍需用户真机试用。未执行的用例不标记通过。
